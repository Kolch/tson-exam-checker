# ЦОН: автоматическая запись на теоретический экзамен

Свободные слоты на теорию в СпецЦОН появляются редко и разбираются за минуты.
Этот проект держит приложение ЦОН в эмуляторе Android у тебя на Маке, каждые
10–20 минут (и ровно в полночь) проверяет свободные даты и сразу пишет в
Telegram. Нажал кнопку «Забронировать» — он сам доходит до конца записи.

> Неофициальный проект, не связан с ЦОН / gov4c.kz. Используешь на свой риск.
> Бронь в приложении **нельзя отменить**, поэтому по умолчанию без твоего
> нажатия ничего не бронируется.

## Что нужно

- **Мак на Apple Silicon** (M1 и новее), ~15 ГБ свободного места. Мак должен
  стоять на зарядке и не засыпать, пока идёт поиск (экран может гаснуть).
- **Номер заявки** из услуги «Первичное получение ВУ». Без него записаться на
  теорию нельзя.
- **Телефон** с номером, зарегистрированным в базе мобильных граждан: на него
  приходят SMS-коды. Подходит iPhone или Android.
- **Telegram**.
- **Claude Code** или **Codex**: ИИ-агент, который всё установит и настроит.

## Как запустить

```bash
git clone https://github.com/Kolch/tson-exam-checker.git
cd tson-exam-checker
```

Дальше открой в этой папке ИИ-агента:

- **Claude Code:** запусти `claude` и напиши `/setup`;
- **Codex:** запусти `codex` и напиши «Настрой мне этот проект по docs/SETUP.md».

Агент установит всё нужное (Android-эмулятор, Appium, Python) и проведёт по
шагам. Руками придётся сделать только то, что агент не может:

1. скачать APK приложения ЦОН (агент подскажет откуда);
2. войти в приложение в окне эмулятора (ИИН, телефон, SMS) и задать код
   доступа;
3. создать Telegram-бота через @BotFather (2 минуты);
4. включить пересылку SMS с телефона на Мак (iPhone: «Переадресация» в
   настройках Сообщений; Android: приложение-пересыльщик SMS);
5. дать доступ в настройках macOS и запретить Маку засыпать.

Вся настройка занимает около часа, большая часть уходит на скачивание.

## Как это работает

```
Мак ─ эмулятор Android ─ приложение ЦОН
        ▲ Appium: СпецЦОН → Запись на теорию → номер заявки → SMS-код → дата
        │
SMS-код с телефона ─► Мак (пересылка iPhone или приложение на Android)
        │
слоты есть ─► Telegram: 🚨 + кнопка «Забронировать»
```

Каждая проверка проходит весь путь заново: приложение кэширует календарь
внутри сессии. Поэтому каждая проверка присылает тебе на телефон SMS-код.
Это нормально, коды подхватываются автоматически.

## Режимы бронирования

В файле `.env`, параметр `BOOKING_MODE`:

| Режим | Что происходит, когда появились слоты |
|---|---|
| `button` (по умолчанию) | сообщение со списком слотов и кнопкой «Забронировать». Нажал — бронирует ближайший |
| `auto` | сам бронирует ближайший слот, до которого не меньше `TSON_MIN_LEAD_H` часов; более близкие предлагает кнопкой |
| `alert` | только уведомление, бронируешь сам в приложении на телефоне |

Можно запретить даты: `TSON_BLACKOUT_FROM` / `TSON_BLACKOUT_TO`.

## Управление из Telegram

`/status`: что происходит · `/stop`: остановить · `/start`: запустить снова ·
`/check`: проверить прямо сейчас.

После успешной брони проверки останавливаются сами.

## Если что-то сломалось

Бот пришлёт ⚠️ с описанием. Открой Claude Code или Codex в папке проекта и
скажи «чекер сломался, почини». У агента есть инструкция
(`docs/troubleshooting.md`). Самое частое:

- раз в ~7 дней приложение разлогинивается. Если в `.env` заданы ИИН и
  телефон, чекер войдёт заново сам, иначе попросит войти вручную;
- после обновления приложения могут поменяться надписи на экранах, и агент
  поправит их по инструкции.

## Приватность

- Номер заявки, код доступа, ИИН, телефон и токен бота лежат только в `.env`
  на твоём Маке и никуда не отправляются, кроме самого приложения ЦОН.
  Уведомления уходят только в твоего Telegram-бота. Скриншоты в них могут
  показывать твои данные (например, ИИН на экране подтверждения брони).
- `.env` и папка `data/` (логи и скриншоты) не попадают в git.
- Когда настраиваешь проект с ИИ-агентом, он видит то, что ты ему
  показываешь или вставляешь в чат. Секреты можно вписать в `.env` самому.

## Удаление

```bash
./scripts/install_daemon.sh remove
```

Потом удали папку проекта и эмулятор: `avdmanager delete avd -n tson`.
